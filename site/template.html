Why this one

Built eight agents deep, every day.

毎日8体を並べて作り込んだ。

Badges heal themselves

「作業中」のまま止まらない

Press Esc mid-turn and no stop event fires, so hook-only tools say "working" forever. junban checks Claude Code's own session records in ~/.claude/sessions and walks the process tree to be sure it is looking at the right pane.

途中で Esc を押すと終了イベントが飛ばず、フックだけのツールは「作業中」を出し続けます。junban は Claude Code 自身のセッション記録 ~/.claude/sessions と照合し、プロセスの親子関係まで見て正しい窓かを確かめます。

Longest wait goes first

待たせた順に呼ぶ

Alt+a always takes you to the agent that has waited longest: questions and permissions before finished work.

Alt+a は、いちばん長く待たせている窓へ飛びます。質問・許可が先、終わった作業が後です。

Names that stay put

相槌で名前が変わらない

Windows are named after the task, optionally by a local model in under a second. "ok", "yes", "進めて" or "ครับ" never rename anything, and a name you set yourself is never touched.

窓には作業内容から名前が付きます。手元のモデルを使えば1秒以内です。「OK」「進めて」「ครับ」では変わらず、自分で付けた名前は上書きしません。

English, 日本語, ไทย

英語・日本語・タイ語

Picked from your locale. Japanese and Thai names are cut by display width, so tabs stay aligned.

ロケールから自動で選びます。日本語やタイ語の窓名は表示幅で切るので、タブが崩れません。

Just tmux and bash

tmux と bash だけ

No daemon, nothing to keep alive. 66 tests, run in CI on Linux and macOS.

デーモンなし、常駐なし。テスト66件を Linux と macOS の CI で回しています。

Install

Two lines. Then press Alt+a.

2行入れて、Alt+a を押すだけ。

1 tmux

set -g @plugin 'Nameless-LLC/junban'

With TPM. No TPM? curl -fsSL https://raw.githubusercontent.com/Nameless-LLC/junban/main/install.sh | bash

TPM の場合。TPM を使わないなら curl -fsSL https://raw.githubusercontent.com/Nameless-LLC/junban/main/install.sh | bash

2 Claude Code

/plugin marketplace add Nameless-LLC/junban
/plugin install junban@junban

Other agents can call scripts/state.sh waiting from any hook.

他のエージェントも、フックから scripts/state.sh waiting を呼べばつながります。

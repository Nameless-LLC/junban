Why this one選ぶ理由

The more agents, the more it pays off.

エージェントが増えるほど、効いてくる。

Badges heal themselves

「作業中」のまま止まらない

Press Esc mid-turn and no stop event fires, so hook-only tools say "working" forever. junban checks Claude Code's own session records in ~/.claude/sessions and walks the process tree to be sure it is looking at the right pane.

途中で Esc を押すと終了イベントが飛ばず、フックだけのツールは「作業中」を出し続けます。junban は Claude Code 自身のセッション記録 ~/.claude/sessions と照合し、プロセスの親子関係まで見て正しい窓かを確かめます。

Longest wait goes first

待たせた順に呼ぶ

Alt+a always takes you to the agent that has waited longest: questions and permissions before finished work.

Alt+a は、いちばん長く待たせている窓へ飛びます。質問・許可が先、終わった作業が後です。

One line on what it needs

何を求めているかを1行で

When an agent asks, needs permission or finishes, the banner and the Alt+f list say in one line what it wants or what came of the turn: "tests pass, PR #12 opened". Phone notifications carry the same line.

エージェントが質問・許可を求めたときや作業を終えたとき、帯と Alt+f の一覧に「何を求めているか／何が起きたか」を1行で出します（例:「テスト成功、PR #12 を作成」）。スマホ通知にも同じ1行が載ります。

Catches the costly habits

高くつく癖を見つける

Two agents in one git tree overwrite each other, so those windows get a ⚠ and Alt+n starts the next one in its own worktree. Agents parked for a day get a dim z and sink to the bottom.

同じ Git の作業場所で2体が動くと互いの変更を上書きします。その窓に ⚠ を付け、Alt+n は別の作業場所（worktree）で次の1体を起動します。1日放置された窓には z が付き、一覧の下に沈みます。

Measures how long they waited

待たせた時間を測る

The guide line shows how long agents sat waiting on you today and your median reply time. Alt+/ adds a bar per day, this week against last, your best day and a streak. It all stays in a local file.

今日エージェントを待たせた合計と、返事までの中央値を案内行に出します。Alt+/ では日ごとの棒グラフ、先週との比較、自己ベスト、連続記録も見られます。データは手元のファイルにだけ残ります。

Names that stay put

相槌で名前が変わらない

Windows are named after the task, optionally by a local model in under a second. "ok", "yes", "進めて" or "ครับ" never rename anything, and a name you set yourself is never touched.

窓には作業内容から名前が付きます。手元のモデルを使えば1秒以内です。「OK」「進めて」「ครับ」では変わらず、自分で付けた名前は上書きしません。

Claude Code, Codex, Gemini

Claude Code・Codex・Gemini

Run them side by side. Codex and Gemini show ✋ with the exact command they want to run; one line sets each one up.

混ぜて並べても同じ掲示板に並びます。Codex と Gemini は実行したいコマンドを ✋ と一緒に出します。導入はそれぞれ1行です。

English, 日本語, ไทย

英語・日本語・タイ語

Picked from your locale. Japanese and Thai names are cut by display width, so tabs stay aligned.

ロケールから自動で選びます。日本語やタイ語の窓名は表示幅で切るので、タブが崩れません。

Just tmux and bash

tmux と bash だけ

No daemon, nothing to keep alive. 124 tests, run in CI on Linux and macOS.

デーモンなし、常駐なし。テスト124件を Linux と macOS の CI で回しています。

Install導入

One line. Then press Alt+a.

1行入れて、Alt+a を押すだけ。

Paste it into a terminal. It installs junban into tmux, reloads it, and connects Claude Code if you have it.

ターミナルに貼り付けるだけです。tmux に junban を入れて読み込み直し、Claude Code があればそちらにもつなぎます。

Terminalターミナル
curl -fsSL https://raw.githubusercontent.com/Nameless-LLC/junban/main/install.sh | bash

Or, depending on what you use

使っているものに合わせて選ぶ場合

TPM
set -g @plugin 'Nameless-LLC/junban'

Add to ~/.tmux.conf, then press prefix + I.

~/.tmux.conf に追記して、prefix + I を押します。

Claude Code
claude plugin marketplace add Nameless-LLC/junban && claude plugin install junban@junban

Only if you installed with TPM. The line above does this for you.

TPM で入れた場合だけ必要です。上の1行なら自動で済みます。

Codex CLI
~/.tmux/plugins/junban/scripts/setup.sh codex

Then open /hooks in Codex once and trust them.

そのあと Codex で一度 /hooks を開き、承認します。

Gemini CLI
~/.tmux/plugins/junban/scripts/setup.sh gemini

Restart Gemini CLI and it is connected.

Gemini CLI を起動し直せばつながります。
